# 学田 Study Farm — 真机冒烟测试清单

按序执行，全部通过方可交付。

## 1. 安装与启动
- [ ] APK 安装成功（minSdk 24 设备，Android 7.0+）
- [ ] 冷启动 < 5 秒（中端机）
- [ ] 首次启动无崩溃，进入 Boot → 农场场景
- [ ] 题库加载日志：各科目题数/章节数显示正确（math 705 题 / env 180 KP）

## 2. 播种 → 答题 → 收获全流程
- [ ] 点击空地块，选择环工知识点播种，扣 1 种子
- [ ] 首次播种未学章节 → 弹出知识点摘要卡（含书名/章节/页码出处）
- [ ] 种子不足时提示去商店
- [ ] 点击已播种地块 → 抽题进入答题界面
- [ ] 答对：作物 growth+1，正反馈动画，SM-2 间隔刷新
- [ ] 答错：显示正确答案+解析（含出处），间隔重置 1 天
- [ ] 连对 3 题 → 暴击 +1 果实
- [ ] growth 达 5 → 可收获，收获产出果实+经验，地块重置
- [ ] 收获后知识点计入图鉴（含出处）

## 3. 数学闯关
- [ ] 章节地图渲染：节点+路径+星级
- [ ] 进入关卡逐题作答，答案默认折叠
- [ ] 提交后自动展开答案+解析+出处
- [ ] 主动展开答案 → 该题判负（防作弊）
- [ ] 结算：≥90% 3星 / ≥70% 2星 / ≥50% 1星 / <50% 未通关
- [ ] 首通奖励（果实+种子）入账
- [ ] 中途退出 → 整关作废（进度不保存，重打）
- [ ] 某章全 3 星 → 解锁 boss 关 + 章末宝箱

## 4. 复习调度与蔫萎
- [ ] next_due 到期 → 地块显示"需浇水"动态标记
- [ ] 农场主界面顶部显示"今日到期 n 块田"
- [ ] 超 next_due 24h 未复习 → 作物蔫萎（变灰停长）
- [ ] 化肥立即恢复蔫萎并刷新 next_due

## 5. 商店与经济
- [ ] 购买种子/化肥/挽回药剂，扣除果实正确
- [ ] 余额不足 → 提示且余额不变
- [ ] 经济操作前后果实总量守恒（无凭空增减）

## 6. 存档
- [ ] 任一行为（播种/答题/收获/购买/通关）3 秒内写盘
- [ ] 导出存档 → 生成带版本号 JSON，可分享
- [ ] 导入合法存档 → 校验版本结构后覆盖
- [ ] 导入低版本档 → 先迁移再覆盖（schema_version 升级）
- [ ] 存档损坏 → 保留副本 + 回滚最近备份（3 份）

## 7. streak
- [ ] 自然日首次学习行为 → streak+1 + 当日奖励
- [ ] 超 1 自然日无行为 → streak 清零
- [ ] 清零后 48h 内用挽回药剂 → 恢复清零前 streak（每月限 1 次）
- [ ] streak 7/30/100 天 → 里程碑奖励

## 8. 杀进程恢复
- [ ] 农场模式答题中杀进程 → 重启保留已完成作答，未完成题丢弃
- [ ] 闯关模式答题中杀进程 → 重启整关作废

## 9. 统计页
- [ ] 环工：答题数/正确率/已掌握知识点数/当前蔫萎数
- [ ] 数学：已通关数/总星数/各章正确率
- [ ] 最近 7 天每日答题柱状图

## 10. 构建指标
- [ ] APK 体积 < 150 MB
- [ ] 启动时间 < 5s（中端机）
